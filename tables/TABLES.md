## How many of these fit in the report

The final report is **4 pages** and the course counts *figures,
tables and captions* against that limit, so most of these tables
cannot all go in the body. A workable split:

- **In the report (3 tables):** `table1_ranking_baselines`, `table2_alpha_sensitivity`, `table3_selection_ppl`, `table3_selection_regret`, `table4_mechanism`, `table5_decomposition`, `table10_benchmark`. These are the ranking table, the sensitivity table and the
  selection table -- the three the starter protocol requires to be
  reported.

  `fig4_nsc_flops_collinearity` and `fig5_selection_regret`.
- **Appendix or `EVALUATION.md`:** `table6_resource_controls`, `table7_within_width`, `table8_bootstrap`, `table9_scoring_cost`. The full set is already
  in [EVALUATION.md](../EVALUATION.md), so the appendix can point
  there instead of reprinting the tables.

composition) can be folded into one sentence of the data section,
and Table 2 can be merged with Figure 1, which plots the same
numbers.

## table5_decomposition

**recommended for the report**

**Exact decomposition of the added prefix term**

The added term decomposes exactly into $T = U + P + R$, an FFN-permutation-invariant part, a positional part and a heterogeneous-attention residual.
